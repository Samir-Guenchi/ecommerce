# Algerie Poste's E-Commerce Platform

This project entails the creation of an app that allows users to post items for sale, and clients to peruse and by them from the app directly. As well as provide an option for delivery in-app. 

---

---

## About 
This in a multi-platform project, that is aimed to deliver services to three types of users: 

**Merchants:**
  Gives them a platform to put their product on sales 

**Citizens:** 
  Provides a marketplace to peruse and buy products. As well have assured delivery nationwide 

**Postalman:** 
  Provides an uber-like functionality to delivery opportunities.  

---

## Features 
- Host seller items 
- An online shop 
- In-app delivery 
- Package tracking 

---

## Modules
Due to the large scale nature of this project, it will be divided into modules, with pre-defined interfaces between them. Please refec to [this schema]() for a visual representation. In totality, we have:
- **Mobile interface**
  - Merchant section 
    - AI based verification system for sellers
    - AI based verification system for items
  - Citizen section 
    - Package tracking services
  - Deliveryman section 
    - Find deliveries
    - Path planning
- **Dashboard** 
  - Statistics for internal consumption. 
- **Backend**
  - Save private user data locally 
  - employ cloud for publicly accessible data, such as item pictures
